## 5. 任务 1：OpenCV 图片处理（30 分）

### 5.1 处理流程

1. 读取 `resources/test_image.jpg` 并检查是否成功；
2. 输出灰度图与 H、S、V 单通道图；
3. 均值、高斯、中值滤波对比；
4. HSV 双区间阈值生成红色掩膜；
5. 对掩膜展示腐蚀、膨胀、开运算、闭运算；
6. 选择<闭运算 / 开运算，按你代码实际选择填写>结果提取外轮廓，按面积筛选，在原图上绘制轮廓与外接矩形；
7. 在原图副本上绘制圆、矩形、文字；绕图像中心旋转 35°；裁剪左上角 1/4（宽、高各取一半）。

### 5.2 关键参数

| 步骤 | 参数 | 取值 |
|---|---|---|
| 均值滤波 | 核尺寸 | 5 × 5 |
| 高斯滤波 | 核尺寸 / σx | 5 × 5 / 1.5 |
| 中值滤波 | 核尺寸 | 5 |
| 红色 HSV 区间 1 | H / S / V | [0, 10] / [100, 255] / [100, 255] |
| 红色 HSV 区间 2 | H / S / V | [170, 179] / [100, 255] / [100, 255] |
| 形态学 | 结构元素 | 5 × 5 椭圆核 |
| 轮廓面积筛选 | [下限, 上限] | [1637.76, 655104]，即图像总像素（1280 × 853 = 1091840）的 0.15% 与 60% |

### 5.3 筛选后的轮廓面积

依据任务要求，筛选后的轮廓面积标明如下（同时标注于 `contours_boxes.png` 的对应外接矩形旁<若图上未标注，请删除本括号说明>）：

| 轮廓编号 | 面积（像素） | 对应区域说明 |
|---|---|---|
| 0 | 3888 | 左下被叶片遮挡、仅露出部分红色区域的花苞 |
| 1 | 44608 | 左侧前景花朵（含画面左边缘相接花朵）构成的红色连通区域 |
| 2 | 222694 | 中、右部多朵花花瓣相互接触形成的同一红色连通区域 |

说明：框选对象为红色连通区域，不要求一个框恰好对应一朵完整的花。轮廓 2 覆盖多朵花，原因是相邻花瓣的红色区域在掩膜中接触连通；面积下限 1637.76 已过滤花瓣缝隙间的细小红色碎块。

### 5.4 效果分析

**（1）读图与颜色转换。** `imread()` 读入 BGR 图像并检查非空；灰度图反映亮度分布；HSV 三通道中，H 通道对颜色类别最敏感，红色花瓣在 H 通道两端（接近 0 与 179）响应明显，S 通道反映颜色纯度，V 通道反映光照明暗，为红色分割提供依据。

**（2）滤波对比。** 均值滤波（5 × 5）平滑最强，花瓣纹理与边缘模糊最明显；高斯滤波（5 × 5，σx = 1.5）中心权重更高，平滑较自然，花瓣边缘保持优于均值滤波；中值滤波（ksize = 5）对孤立噪点抑制好，对花瓣渐变纹理的破坏相对最小。三者均未使花朵主体轮廓消失，预处理强度适中。

**（3）红色提取。** 红色跨越 H 区间两端，采用双区间 `inRange()` 后取并集，花瓣主体被完整提取。**红色**：花瓣高饱和区域全部进入掩膜；**黄色边缘**：花尖黄色与橙黄色区域 H 不在红色区间内，被有效排除，轮廓止于红黄交界；**阴影**：花朵基部与花瓣间的暗色阴影 V 值较低，被 V ≥ 100 的下限抑制，未形成大面积误检，个别残留碎块由面积筛选去除。

**（4）形态学与轮廓。** 腐蚀使红色区域收缩、去除细小凸出；膨胀使区域扩张、连接窄断裂；开运算去除孤立小白噪点；闭运算填充花瓣内部小孔并连接窄断裂。最终选择<闭运算 / 开运算>结果提取外轮廓（`RETR_EXTERNAL`），按 [1637.76, 655104] 面积筛选后保留 3 个轮廓，绘制绿色轮廓、红色外接矩形并标明面积。

**（5）绘制与变换。** 在原图副本上绘制圆、矩形与文字；使用 `getRotationMatrix2D()` 绕图像中心旋转 35° 后由 `warpAffine()` 完成变换；裁剪 `Rect(0, 0, width/2, height/2)` 得到左上角 1/4 子图。
