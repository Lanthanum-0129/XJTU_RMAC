# task_3 跟踪小结

- 视频参数：1440x1080，30 FPS
- 预处理后端：GPU (OpenCV CUDA)
- 检测方法：HSV双掩膜 + Hough圆环 + 轮廓补充。通过内部像素密度区分靶标(ACTIVE)与单圆圈(INACTIVE)。
- 防误识别：利用先验知识，目标中心与旋转中心距离必须在 [1.2倍半径, 6倍半径] 之间，彻底过滤科技核心与横幅。
- 中心估计（核心修复）：废除不可靠的R标志主导逻辑。优先使用多扇叶几何中心，辅以Kasa圆拟合。R标志仅用于辅助验证和可视化。
- 多目标跟踪：维护 Track 列表，基于欧氏距离和半径差进行稳健最近邻匹配。废除错误的角速度预测，消除滞后。
- 状态管理：靶标击中后状态降级为 INACTIVE (黄色)，新靶标分配新 ID (绿色)。
- 丢失容忍：50 帧。
