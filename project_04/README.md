## 总结与思考

- 观察日志(未写入此文档)可发现，训练后期存在典型的过拟合与学习率过度衰减现象，因而在深度学习中，训练轮数并非越多越好：盲目增加训练轮数不仅浪费算力，还会损害模型性能。合理依赖 best.pt 权重与早停机制，是保证模型在测试集上表现优异的关键
- 比对不同训练策略，发现进行伪标签半监督学习后，模型在验证集上的核心指标 mAP50-95 从 Baseline 的 0.609 显著提升至 0.638，证明了该策略的有效性
